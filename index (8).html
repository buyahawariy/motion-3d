    Tutorial

    Panduan singkat dari awal sampai video jadi.

    1. Pilih skill dan tonton contohnya

    Buka tab Skill, pilih skill di dropdown, lalu lihat sub-tab Ringkasan dan Video.

    2. Pasang skill di Claude

    Di sub-tab Isi, tekan Unduh SKILL.md lalu tambahkan sebagai skill di Claude (letak menunya bisa berbeda sesuai versi aplikasi). Setelah itu kirim perintah dari sub-tab Cara pakai.

    3. Ambil API key Google AI Studio
    1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
    2. Klik Create API key, lalu salin key-nya.
    3. Di tab Narator, tempel di kolom API key dan tekan Simpan.

    Key disimpan di browsermu dan dikirim langsung ke Google.

    4. Buat narasi suara

    Di tab Narator pilih suara, isi gaya bicara dan naskah, lalu tekan Buat suara. Hasilnya bisa diunduh sebagai WAV.

    5. Render video

    Ikuti tahap di skill yang kamu pilih. Unggah rekaman suara ke Claude agar dirender menjadi video vertikal 9:16.

    6. Ajak teman lewat affiliasi

    Di tab Affiliasi, daftar dan tunggu persetujuan admin. Setelah disetujui, bagikan link unikmu dan dapatkan komisi dari tiap pembelian Pro.
